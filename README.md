# Sistema de Feedbacks

Projeto desenvolvido para a disciplina de Extensão - Programação Web.

## Funcionalidades

- Cadastro de feedbacks
- Listagem de feedbacks
- Remoção de feedbacks

## Tecnologias

- Node.js
- Express.js
- EJS

## Rotas

/ -> Página inicial

/feedbacks/enviar -> Cadastro do feedback

/feedbacks/lista -> Lista de feedbacks

/feedbacks/remover -> Remove feedback
